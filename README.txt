VFA LEAGUE HUB — PLAYOFF BOX FIX + RETRO BOWL RESTORED

This update repairs the Playoffs page styling so each matchup appears as a card with individual boxed team panels and logos. It also restores VFA Retro Bowl as a Games dropdown link on all pages and adds a Retro Bowl card on the homepage.

UPLOAD
1. Download and unzip this package.
2. Open the exact GitHub repository used by your live VFA League Hub site.
3. Back up the current files first.
4. Upload/replace the files inside this folder (not the folder itself) into the repository root.
5. Commit all changes together in one commit.
6. In Settings → Pages, verify the correct branch and folder are published.
7. Wait for deployment, then hard-refresh the site (Mac: Cmd+Shift+R).

Do not delete all files in a separate commit. This package includes retro-bowl.html.
